## Hi, I'm Abdul 👋

I am a Software Engineering student at Toronto Metropolitan University with a background in backend development, applied AI, and embedded systems. My work has focused on building reliable software and understanding how it behaves in production.

As an AI Software Engineering Intern at the Workplace Safety and Insurance Board, I developed backend services for enterprise AI applications using Python, Flask and REST APIs, deployed on Azure App Service and Azure Functions. I secured infrastructure with Azure SQL, Key Vault and Docker, and took part in backend code reviews covering API routing, architecture, security and maintainability.

I founded Motivez, a cross-platform social planning app, and led its development using React Native, TypeScript, Python, Supabase and Redis. I also joined the web development team at Ibtikar Toronto, where I helped build and maintain the organization's website.

My project work covered a wide range. I trained and evaluated a text classifier with cross-validation, built a prompt evaluation harness that compared model outputs using bootstrap confidence intervals, and developed a retrieval-based document assistant with FAISS. On the hardware side, I designed an 8-bit processor in VHDL on an FPGA and programmed a maze-navigating robot in assembly on an HCS12 microcontroller. Java and C/C++ were my strongest languages, supported by Python, SQL and TypeScript.

I earned the AWS Certified Cloud Practitioner, Microsoft Certified: Azure Fundamentals, and IBM Introduction to Artificial Intelligence certifications, and focused my interests on cloud engineering, applied AI, and the boundary between software and hardware.
